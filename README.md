🧮 Modern Calculator

A simple and interactive calculator built using HTML, CSS, and JavaScript.

✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear (C) button
- Delete (DEL) button
- Error handling for division by zero
- User-friendly interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

📂 Project Structure

- index.html
- style.css
- script.js
